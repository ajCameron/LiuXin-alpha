# metadata_rich_db_1

Small operational metadata fixture generated by:

`tests.support.test_databases.metadata_rich_db_1.populate_bundle`

This bundle contains a FRBR-native LiuXin database plus tiny on-disk book
payloads under `metadata_store/books/`. It is intended for metadata contract
tests that need representative rows without rebuilding the database on every
run.

Coverage:

- 4 WEMI stacks with varied work/expression/manifestation/item fields.
- Human and organisation agents with author, editor, translator, and publisher links.
- Tags, labels, genres, subjects, series, languages, notes, comments, synopses, annotations, and identifiers.
- One file-backed store with 5 ebook file rows covering primary and alternate file roles.

See `build_summary.json` for row counts and this built artifact's database
checksum.
