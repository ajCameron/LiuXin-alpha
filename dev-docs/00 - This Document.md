This is not the user manual. This is a collection of resources and thoughts intended for developers and others who want
to work on LiuXin on a philosophical or practical level.

It is intended to be a grab bag of notes - a working lab book.
If you're working on a plugin, and you want to make notes on how it works (in addition to code comments) put them here.
If you're converting some of the code base to rust, put notes on that here.
Anything else you can think of which may be useful (bearing in mind applicable law), put it here!
