# Contributing and tools

- [Local setup](../../README.md), [coding guide](<../Coding Guide.md>) and
  [style guide](<../Style Guide.md>): environment and conventions.
- [Testing index](testing/README.md) and [test streams](test-streams.md): select a
  focused lane, investigate failures and preserve useful diagnostics.
- [Packaging](packaging.md): installed resources, dependencies and deployment bundles.
- [Quality gates](../architectural_reviews/maintainability-quality-gates.md),
  [layer rules](../architectural_reviews/layer-direction-ratchet.md) and
  [import checks](../architectural_reviews/import-footprint-ratchet.md): active enforcement.

The [docstring completion plan](project-docstrings-completion-plan.md) and
[work inventory](project-docstrings-work-units.json) record a completed campaign.
Their counts and review hashes are historical evidence, not a request to repeat
the campaign whenever source files change.
